Deploy:
1. GitHub fayllarini shu paket bilan to'liq almashtiring.
2. Render → Manual Deploy → Clear build cache & deploy.
3. Tilda ichida oldin qo'yilgan bayramona overlay/fon kodlari bo'lsa olib tashlang.
4. Brauzerda Ctrl + F5.
