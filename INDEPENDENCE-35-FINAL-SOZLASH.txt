ALL FINANCE v29 — Mustaqillik 35 yilligi bayramona dizayn

NIMA QILINDI
1. Asosiy baza, server, admin panel, foydali ma'lumotlar JSON tizimi, jamoa admini va yangiliklar modullari saqlab qolindi.
2. Saytga alohida dizayn qatlami qo'shildi:
   assets/css/independence-35.css
3. Barcha public sahifalarga shu CSS ulandi.
4. Barcha asosiy hero/page-hero bloklariga 35 yillik bayram belgisi qo'shildi.
5. 4 til bo'yicha badge matni alohida qo'yildi:
   UZ: O‘zbekiston Respublikasi Mustaqilligining 35 yilligi
   RU: 35 лет независимости Республики Узбекистан
   EN: 35th Anniversary of Independence of Uzbekistan
   ZH: 乌兹别克斯坦共和国独立35周年
6. Header, hero, page hero, kartalar, foydali ma'lumotlar paneli va footer bayramona ranglar bilan bezatildi.

RENDERDA O'RNATISH
1. GitHub repozitoriydagi eski fayllarni ushbu paket ichidagi fayllar bilan to'liq almashtiring.
2. Render sozlamalari o'zgarmaydi:
   Build Command: node scripts/verify-build.js
   Start Command: node server.js
   Health Check Path: /health
3. Renderda Manual Deploy -> Clear build cache & deploy qiling.
4. Brauzerda Ctrl + F5 bilan qayta oching.

TILDA VARIANT
Agar bayramona dekorni Tilda sahifasiga ham qo'shmoqchi bo'lsangiz:
1. Tilda sahifasida HTML block qo'shing.
2. Paketdagi TILDA-INDEPENDENCE-35-SNIPPET.html fayli ichidagi kodni shu block ichiga qo'ying.
3. Publish qiling.

QAYTARISH
Bayramona dizaynni olib tashlash uchun public HTML fayllardagi independence-35.css linkini olib tashlash kifoya.
Server va baza fayllariga tegilmagan.
