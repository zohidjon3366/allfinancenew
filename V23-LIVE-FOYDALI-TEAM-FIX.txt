ALL FINANCE v23 — Jamoa va Foydali baza tuzatishlari

1) Bosh sahifadagi Jamoa bo‘limi
- Endi index.html, ru/index.html, en/index.html va zh/index.html sahifalaridagi jamoa kartalari ham /api/team orqali olinadi.
- /admin/jamoa.html panelida xodim ma’lumotlari yoki rasmi o‘zgartirilsa, bosh sahifadagi jamoa bo‘limi ham yangilanadi.
- Muhim fayllar:
  assets/js/team-client.js?v=23
  index.html
  ru/index.html
  en/index.html
  zh/index.html

2) Foydali baza — alohida ichki sahifalar
- Buxgalter taqvimi, 2026 ish kunlari va eng kam ijara stavkalari endi statik qo‘lda yozilgan jadval emas.
- Har bir sahifa ichida BuxgalterPRO ma’lumotlari server proxy orqali jonli olinadi.
- Foydalanuvchi tashqi saytga avtomatik o‘tib ketmaydi.
- Ma’lumotlar ALL FINANCE sahifa dizayni ichidagi keng karta/iframe oynada ko‘rsatiladi.

Ichki manzillar:
/foydali-calendar.html      → /buxpro/calendar
/foydali-workdays.html      → /buxpro/workdays
/foydali-rent.html          → /buxpro/rent
/foydali-laws.html          → /buxpro/laws
/foydali-links.html         → /buxpro/links

3) Server endpointlari
/server.js ichiga quyidagilar qo‘shildi:
/buxpro/calendar
/buxpro/workdays
/buxpro/rent
/buxpro/laws
/buxpro/links
/buxpro/raw?url=...

4) Render uchun
Build Command o‘zgarmaydi:
node scripts/verify-build.js

Start Command o‘zgarmaydi:
node server.js

Health Check Path:
/health

5) Deploy qilish tartibi
- GitHub’dagi fayllarni ushbu paket bilan to‘liq almashtiring.
- Ayniqsa quyidagi fayllar yangilangan bo‘lishi shart:
  server.js
  assets/css/style.css
  assets/js/team-client.js
  assets/js/useful-live.js
  index.html
  ru/index.html
  en/index.html
  zh/index.html
  foydali-calendar.html
  foydali-workdays.html
  foydali-rent.html
  ru/en/zh ichidagi xuddi shu sahifalar

- Render’da Manual Deploy → Clear build cache & deploy qiling.
- Brauzerda Ctrl + F5 bosing.

6) Eslatma
BuxgalterPRO ma’lumotlari jonli olinishi uchun Render serveridan buxgalterpro.uz saytiga internet/DNS ulanishi bo‘lishi kerak.
Agar manba sayt vaqtincha ishlamasa, sahifa ichida xatolik xabari chiqadi va yangilash tugmasi orqali qayta urinadi.
